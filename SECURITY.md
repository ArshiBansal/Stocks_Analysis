# Security Policy

## Supported Versions

This project is actively maintained on the latest version available in the repository.

## Reporting a Vulnerability

The security of this project is important. If you discover a security vulnerability, please do **not** create a public GitHub issue.

Instead, report the issue privately by contacting the project maintainer with:

* A description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Any suggested fixes (if available)

We will review all legitimate reports and make every effort to address confirmed vulnerabilities in a timely manner.

## Disclosure Policy

Please allow reasonable time for the vulnerability to be investigated and resolved before publicly disclosing it.

We appreciate responsible disclosure and your efforts to help improve the security of this project.
