\# Contributing to Magnificent 7+ AI Stock Forecasting System



Thank you for your interest in contributing!



Whether you're fixing bugs, improving documentation, enhancing the Streamlit dashboard, or experimenting with forecasting models, your contributions are welcome.



\## Getting Started



\### 1. Fork the Repository



Click the \*\*Fork\*\* button at the top-right of this repository.



\### 2. Clone Your Fork



```bash

git clone https://github.com/YOUR\_USERNAME/REPOSITORY\_NAME.git

cd REPOSITORY\_NAME

```



\### 3. Install Dependencies



```bash

pip install -r requirements.txt

```



\### 4. Run the Application



```bash

streamlit run app.py

```



\## Ways to Contribute



\* Fix bugs

\* Improve documentation

\* Enhance UI/UX

\* Add new forecasting models

\* Improve model evaluation metrics

\* Add tests

\* Improve performance



\## Branch Naming



Examples:



```text

feature/add-confidence-intervals

fix/yfinance-loading-error

docs/update-installation-guide

```



\## Pull Request Guidelines



\* Keep PRs focused on a single change.

\* Write clear commit messages.

\* Update documentation when necessary.

\* Test your changes before submitting.

\* Add screenshots for UI changes when applicable.



\## Need Help?



Open an issue and describe the problem or idea clearly.



Happy contributing!
